# Vortex Engine 🌪️

**Vortex Engine** is an experimental, high-quality **3D custom rendering engine** written in **Python**, built on top of **Panda3D**.

The goal of this project is to explore how far a modern rendering pipeline can be pushed using Python—focusing on rendering quality, engine architecture, and low-level control rather than rapid game development.

> ⚠️ **Project Status:** Currently **paused / on hold**.
> The codebase is incomplete and under architectural rethinking before development resumes.

---

## Vision

Vortex Engine is **not** a game template or a thin wrapper around Panda3D. It aims to be a custom engine layer that provides:

* High-quality real-time rendering
* Custom lighting and shading systems
* Modern rendering concepts (PBR, post-processing, etc.)
* Clean, modular engine architecture
* Deep control over the rendering pipeline in Python

This is primarily a **learning, research, and experimentation project**, not a production-ready engine.

---

## Built With

* **Python 3**
* **Panda3D** (rendering, windowing, scene graph)
* **GLSL shaders** (planned / partial)

## Current State

* Core project structure exists
* Early experiments with lighting and rendering
* No stable API
* No release builds
* Features may be incomplete, disabled, or broken

Development is paused to rethink architecture, scope, and long-term direction.

---

## Planned Features (Conceptual)

These are **intentions**, not guarantees:

* Physically Based Rendering (PBR)
* Custom lighting pipeline
* Post-processing effects (bloom, tone mapping, SSAO)
* Modular engine systems
* Scene and asset management
* Debug and visualization tools

---

## Why Panda3D?

Panda3D provides:

* A mature and flexible renderer
* Python-first workflow
* Access to low-level graphics features
* Freedom to experiment without rebuilding a renderer from scratch

Vortex Engine builds **on top of** Panda3D, not against it.
